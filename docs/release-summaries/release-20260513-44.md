# release-20260513-44

Production release for courier scheduled dispatch hardening, courier offer countdown UX, and Telegram courier notifications.

## Included changes

- Hardened scheduled final matching:
  - reliability guard for couriers;
  - re-offer cooldown;
  - max attempts per courier per order;
  - TTL 45 seconds for personal courier offers;
  - improved tests and documentation.

- Courier offer UX:
  - visible 45 second countdown timer;
  - urgency states;
  - server-side protection against accepting expired offers;
  - realtime card close for expired/unavailable offers.

- Telegram courier binding:
  - one-time Telegram bind token flow;
  - hashed token storage;
  - `/start <token>` webhook binding;
  - courier notification preferences;
  - real Telegram Bot API `sendMessage`;
  - unlink/relink support.

## Required env/config

- TELEGRAM_BOT_TOKEN
- TELEGRAM_BOT_USERNAME
- TELEGRAM_BIND_TOKEN_TTL_MINUTES
