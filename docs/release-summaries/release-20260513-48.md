# release-20260513-48

Telegram send config unification release.

## Included changes

- Unified Telegram send runtime config on `config('services.telegram.bot_token')`.
- Hardened scheduled Telegram notification send failures.
- Hardened admin Telegram notification send failures.
- Added controlled failure when Telegram token is missing.
- Improved Telegram error logging with sanitized endpoint, response code and description.
- Added regression tests for canonical token usage.
- Updated Telegram troubleshooting documentation.

## Deployment notes

Run standard release gate before deploy.

## Smoke checklist

- Admin service Telegram notification sends successfully.
- Admin marketing Telegram notification sends successfully when preference is enabled.
- Audit log status is `sent`.
- Audit log `telegram_error` is empty for successful sends.
- Scheduled offer Telegram notification sends successfully.
- No Telegram API 404 from empty/wrong bot token.
