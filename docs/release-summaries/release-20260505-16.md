# release-20260505-16

## Summary
- Added dispatch gating for subscription execution orders.
- Prevented future scheduled subscription orders from being offered too early.
- Added dispatch_available_at to orders.
- Subscription first run now follows payment cutoff: before 12:00 today, after 12:00 tomorrow.
- Subscription starts_at/ends_at now align with first execution run.
- Added preferred time windows including 18:00–20:00.
- Blocked courier start before dispatch window.

## Manual test focus
- If package is paid after 12:00, first execution is scheduled tomorrow.
- Future execution order is not visible to couriers before dispatch_available_at.
- Execution becomes visible only when dispatch window opens.
- Courier cannot start a deferred future execution early.
