# release-20260505-31

## Summary
- Added private-house toggle to /client/order/create.
- Added conditional address validation for apartment vs private house flows.
- Entrance, floor and apartment are now required only for apartment buildings.
- Intercom remains optional.
- Added required field indicators (*) for address detail fields.
- Added validation error handling with auto-scroll and focus to invalid address fields.
- Preserved apartment field values when toggling private-house mode on/off.
- Private-house mode now collapses apartment detail fields in UI.
- Address building_type is now propagated consistently through order snapshots and saved addresses.
- Fixed Alpine inline runtime syntax issue that caused frontend bootstrap failure in browser-e2e tests.

## Manual test focus
- Regular apartment order requires entrance/floor/apartment.
- Private house order can be submitted without apartment details.
- Toggling private-house mode preserves previously entered values.
- Validation errors scroll user back to address block and focus invalid field.
- Subscription checkout uses the same validation logic.
- /client/order/create loads without JS runtime errors.
