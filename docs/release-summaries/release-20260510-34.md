# release-20260510-34

## Summary
- Added awaiting-client-confirmation lifecycle after courier submits completion proof photos.
- Courier proof submission now moves completion request to `awaiting_client_confirmation`.
- Added configurable auto-confirm timeout via `ORDER_COMPLETION_CONFIRMATION_TIMEOUT_MINUTES`.
- Added client/courier UI copy for awaiting confirmation instead of showing active execution.
- Added countdown/expired auto-confirm messaging.
- Added auto-complete scheduler command: `orders:auto-complete-awaiting-confirmation`.
- Added completion lifecycle metadata, resolution fields, notifications, and audit events.
- Courier earnings are finalized on client confirmation or system auto-completion through existing finalize flow.
