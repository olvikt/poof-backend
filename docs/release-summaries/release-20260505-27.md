# release-20260505-27

## Summary
- Reworked client bell into a pending-confirmations dropdown.
- Added per-item deep links for one-time orders and subscription execution orders.
- Added target titles, subtitles, labels and URLs to pending confirmation payload.
- Added highlight support for /client/orders.
- Added highlight and auto-open details support for /client/subscriptions.
- Added graceful fallback for invalid subscription highlight params.
- Added smooth scroll to highlighted pending-confirmation items.
- Improved dropdown mobile positioning and long subtitle handling.

## Manual test focus
- After courier completes a one-time order, client bell shows dropdown item linking to /client/orders.
- After courier completes a subscription execution order, client bell shows dropdown item linking to /client/subscriptions.
- Clicking a dropdown item highlights the exact order/execution order.
- Dropdown does not render when there are no pending confirmations.
- Invalid/stale subscription highlight params do not crash the page.
