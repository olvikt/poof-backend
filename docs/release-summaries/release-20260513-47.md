# release-20260513-47

Admin Telegram courier management release.

## Included changes

- Telegram status columns in admin courier list.
- Filters for Telegram linked/unlinked couriers.
- Filters for order and marketing notification preferences.
- Single courier Telegram notification action.
- Bulk Telegram notification action with confirmation.
- Preference-aware delivery policy.
- Emergency/service override support.
- Telegram admin notification audit log.
- Ukrainian admin UI texts.
- Documentation and tests for admin Telegram flow.

## Deployment notes

Run standard release gate before deploy.

## Smoke checklist

- Admin Couriers table shows Telegram columns.
- Telegram linked/unlinked filters work.
- Single Telegram notification sends to linked courier.
- Unlinked courier is skipped.
- Marketing notification respects marketing preference.
- Emergency/service notification can override preference when intended.
- Bulk send shows sent/skipped/failed summary.
- Audit records are written to telegram_admin_notifications.
