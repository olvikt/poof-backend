# release-20260510-33

## Summary
- Increased and documented courier verification upload limits to prevent nginx-level `413 Request Entity Too Large` on normal phone photo uploads.
- Aligned nginx, PHP-FPM, and Laravel upload expectations at 20 MB for courier verification documents/photos.
- Added server ops checks/manual verification steps so releases validate upload-size contracts before/after deploy.

## Deploy commands (server-side)
```bash
cd /var/www/poof
git pull
php artisan optimize:clear
php artisan config:cache

# nginx
sudo nginx -t
sudo systemctl reload nginx

# php-fpm
sudo systemctl reload php8.3-fpm

# contract checks
bash scripts/check-server.sh
```

## Manual test steps
1. Upload courier verification image under allowed limit; expect success and pending review state.
2. Upload file above Laravel limit (over 20 MB); expect friendly Laravel validation error, not nginx 413.
3. Upload a normal phone photo; confirm no nginx `413 Request Entity Too Large`.
4. Login as admin and confirm submitted verification request is visible in courier verification requests list.

## Ops verification commands (413 prevention)
```bash
# nginx effective config contains explicit limit
sudo nginx -T 2>/dev/null | grep -n "client_max_body_size"

# PHP limits are aligned
php -i | grep -E "upload_max_filesize|post_max_size"
```
